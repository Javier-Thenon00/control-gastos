# 💸 Control de Gastos

Aplicación web para registrar ingresos y gastos, organizar movimientos por categoría y consultar el balance personal desde una interfaz simple y adaptable.

**No requiere instalación ni servidor:** funciona directamente en el navegador y guarda los movimientos en el almacenamiento local del dispositivo.

## ✨ Funcionalidades
- Registrar ingresos y gastos con descripción, importe, categoría y fecha.
- Consultar balance, ingresos y egresos totales.
- Filtrar movimientos por tipo.
- Eliminar movimientos.
- Exportar los movimientos a CSV para abrirlos en Excel.
- Guardado automático en `localStorage`.
- Diseño adaptable a computadoras y celulares.

## 🚀 Cómo usarlo
1. Abrí el archivo `index.html` en un navegador moderno.
2. Completá el formulario para cargar un ingreso o gasto.
3. Revisá los indicadores y el historial.
4. Usá los filtros para encontrar movimientos o el botón de exportación para descargar un CSV.

## 🧰 Tecnologías
HTML5 · CSS3 · JavaScript (Vanilla) · LocalStorage

## 🔒 Privacidad
Los datos se guardan únicamente en el navegador utilizado. No se envían a ningún servidor. Si borrás los datos del sitio o cambiás de navegador/dispositivo, los movimientos pueden perderse. Exportá un CSV para conservar una copia.

## 📌 Alcance
Proyecto educativo de portfolio. No reemplaza una aplicación bancaria ni brinda asesoramiento financiero.
